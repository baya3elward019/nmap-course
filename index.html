// 03 — KALI SETUP

تشغيل Nmap على Kali Linux

ثلاث خطوات سريعة من التيرمنال إلى أول نتيجة فحص.

STEP 01

افتح Terminal

من قائمة Kali أو بالاختصار Ctrl + Alt + T عند توفره.

STEP 02

تأكد من التثبيت

نفّذ nmap --version، وإذا لم تكن الأداة مثبتة فاستخدم مدير الحزم.

STEP 03

ابدأ بفحص مختبرك

نفّذ nmap 192.168.56.10 بعد التأكد من صلاحيتك لفحص الهدف.

kali@kali: ~/terminal
kali@kali:~$ nmap --version Nmap version 7.x kali@kali:~$ sudo apt update kali@kali:~$ sudo apt install nmap kali@kali:~$ nmap 192.168.56.10 Nmap scan report for 192.168.56.10 Host is up (0.0012s latency). PORT STATE SERVICE 22/tcp open ssh 80/tcp open http 443/tcp open https kali@kali:~$ █
النتائج في هذا العرض توضيحية ومحاكاة وليست ناتجة عن فحص فعلي.

// ESSENTIAL FLAGS — PART 01

أهم 6 فلاجز لازم تعرفهم أولاً

ركز على وظيفة الفلاج والأمر. اضغط على أي أمر لنسخه، وجربه على جهاز المختبر فقط.

-A

فحص شامل

يكشف نظام التشغيل وإصدارات الخدمات ويشغّل السكربتات الافتراضية وتتبع المسار.

sudo nmap -A 192.168.56.10
-O

تحديد نظام التشغيل

يحاول تخمين هل الهدف Linux أو Windows من بصمة الشبكة.

sudo nmap -O 192.168.56.10
-sn

اكتشاف الأجهزة فقط

يتحقق من الأجهزة النشطة بدون فحص المنافذ.

nmap -sn 192.168.56.0/24
-Pn

تجاوز اكتشاف الأجهزة

يفترض أن الهدف متصل ويبدأ الفحص حتى لو لم يرد على اكتشاف المضيف.

nmap -Pn 192.168.56.10
-p

اختيار المنافذ

يفحص منافذ تختارها أنت بدلاً من القائمة الافتراضية.

nmap -p 22,80,443 192.168.56.10
-sV

إصدار الخدمة

يعرض اسم الخدمة ويحاول كشف الإصدار مثل OpenSSH أو Apache.

nmap -sV 192.168.56.10
// ESSENTIAL FLAGS — PART 02

الفلاجز العملية اللي هتستخدمها فعلاً

أنواع فحص TCP وUDP مع سكربتات Nmap الشهيرة.

-sC

السكربتات الافتراضية

يشغّل سكربتات NSE الافتراضية للحصول على معلومات إضافية.

nmap -sC 192.168.56.10
--script

اختيار سكربت معين

تحدد اسم السكربت؛ هنا نقرأ عنوان صفحة HTTP.

nmap --script http-title -p 80 192.168.56.10
-sT

TCP Connect Scan

ينشئ اتصال TCP طبيعي لاختبار المنافذ، ويمكن استخدامه دون صلاحيات raw packets.

nmap -sT 192.168.56.10
-sU

UDP Scan

يفحص منافذ UDP مثل DNS على المنفذ 53. أحياناً لا يمكن الجزم بحالة المنفذ.

sudo nmap -sU -p 53 192.168.56.10
-sS

TCP SYN Scan

فحص TCP شائع يرسل SYN ويحلل الرد، ويتطلب صلاحيات مناسبة.

sudo nmap -sS 192.168.56.10
-T4

سرعة الفحص

قالب توقيت أسرع يناسب غالباً المختبرات والشبكات المستقرة.

nmap -T4 192.168.56.10
💡 فرق مهم: -sC سكربتات افتراضية، أما --script فتختار به سكربتًا محددًا.

// 09 — REAL-WORLD WORKFLOW

سيناريو عملي كامل

افترض أنك مسؤول عن جرد خدمات جهاز تجريبي بعنوان 192.168.56.10.

01 / HOST DISCOVERY

تأكد من استجابة الجهاز

nmap -sn 192.168.56.10

يفحص اكتشاف المضيف دون فحص المنافذ.

02 / PORT ENUMERATION

اعرض منافذ محددة

nmap -p 22,80,443 192.168.56.10

يحدد حالة منافذ SSH وHTTP وHTTPS.

03 / VERSION DETECTION

حدد إصدارات الخدمات

nmap -sV -p 22,80,443 192.168.56.10

يحاول التعرف على البرنامج وإصداره إن أمكن.

04 / SAVE RESULTS

احفظ تقرير الفحص

nmap -sV -oN report.txt 192.168.56.10

ينشئ تقريرًا نصيًا يمكن الرجوع إليه لاحقًا.
